# Mahmoud Zaouchi - Personal Portfolio

A personal portfolio website created with **HTML5** as part of an HTML checkpoint project.

The website presents my professional profile, technical skills, work experience, projects, education, certifications, and contact information.

## 🚀 Features

* Responsive HTML structure
* Semantic HTML5 elements
* Navigation bar with local links
* Personal profile section
* Profile image
* Professional experience
* Education and certifications
* Technical skills
* Projects showcase
* Experience table
* Embedded YouTube video
* Downloadable CV
* Contact form
* Social media links
* Footer with navigation

## 🛠️ Technologies

* HTML5
* Semantic HTML
* YouTube Embed
* HTML Forms
* HTML Tables
* HTML Lists
